# Focus Contract — Guia Operacional

## Comandos Principais
1. Consultar status: `focus-contract agent status --json`
2. Registrar handoff: `focus-contract agent handoff --changed "..." --next "..."`
3. Concluir marco: `focus-contract agent complete-milestone --completed "..." --next-milestone "..." --next-block "..."`
4. Alternar foco: `focus-contract agent switch --to "<id>" --reason "milestone_completed" --changed "..." --next "..."`
