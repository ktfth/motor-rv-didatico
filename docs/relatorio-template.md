# Relatório de etapa — formato obrigatório

Primeira linha: `<papel> — <fase> — <APROVADO|DEVOLVIDO|CONCLUÍDO|PARCIAL>`.

## 1. O que fiz
Arquivos criados/alterados, um por linha, com uma frase do que mudou.

## 2. Testes executados
Comando exato, resultado (passou/falhou, contagem), tempo. Colar a última linha de saída de
cada comando. Benchmarks: commit, máquina, kernel, flags.

## 3. O que não fiz
Itens do pedido não entregues e por quê.

## 4. Riscos e dúvidas
Decisões tomadas sem ADR (para o orquestrador formalizar), suposições, pontos que outro papel
precisa confirmar. Pedidos de ADR vêm aqui com texto pronto: contexto, decisão, alternativas,
consequências.

## 5. Próximo passo sugerido
Qual papel deve entrar e com que entrada.
